
# MARVEL MLOps

## Descripción
Proyecto de Machine Learning enfocado en el análisis y clasificación de diálogos del Universo Cinematográfico de Marvel.

## Objetivo
Desarrollar un flujo de trabajo MLOps que permita preparar datos, entrenar, evaluar, registrar, automatizar y desplegar modelos de clasificación.

## Modelos
- Regresión Logística
- Random Forest
- Support Vector Machine (SVM)

## Tecnologías
- Python
- Pandas
- NumPy
- Scikit-learn
- Git y GitHub
- DVC
- MLflow
- Apache Airflow
- FastAPI
- Docker
- GitHub Actions

## Estructura
- data/: datos originales y procesados
- src/: código fuente
- models/: modelos entrenados
- reports/: resultados y evaluaciones
- tests/: pruebas automatizadas
- notebooks/: análisis exploratorio
